# Предпросмотр Drops для FunPay Cardinal

Плагин рассчитан на sidor0912/FunPayCardinal. Загрузите tdm_lot_preview.py через меню плагинов бота Cardinal. Если команда /tdm_lots не появилась после загрузки, перезапустите Cardinal один раз.

## Подключение контейнеров

Передайте обоим сервисам один и тот же ORCHESTRATOR_LOT_PREVIEW_TOKEN длиной от 32 символов. Значение храните в локальных файлах окружения Compose. Если сервисы делят один localhost, дополнительных параметров не нужно.

Для отдельных контейнеров создайте на VPS отдельный каталог /opt/tdm-light-orchestrator/cardinal-ipc с владельцем 10001:10001 и режимом 0750. Добавьте к существующим volumes оркестратора:

```yaml
- /opt/tdm-light-orchestrator/cardinal-ipc:/run/tdm-cardinal
```

Добавьте к volumes Cardinal тот же каталог с доступом только на чтение:

```yaml
- /opt/tdm-light-orchestrator/cardinal-ipc:/run/tdm-cardinal:ro
```

Добавьте в environment обоих сервисов:

```yaml
ORCHESTRATOR_CARDINAL_SOCKET: /run/tdm-cardinal/preview.sock
ORCHESTRATOR_LOT_PREVIEW_TOKEN: ${ORCHESTRATOR_LOT_PREVIEW_TOKEN:?set a local preview token}
```

Сокет доступен владельцу и группе 10001, а также root. Если Cardinal работает от другого непривилегированного пользователя, добавьте сервису дополнительную группу 10001. Пересоздайте оба сервиса через их Compose-проекты. Если после аварийного завершения остался старый сокет, удалите preview.sock при остановленном оркестраторе и запустите сервис снова.

## Проверка в Telegram

1. В боте оркестратора откройте «Предпросмотр лота», укажите игру, отметьте все кампании лота и сохраните выбор.
2. В личном чате с ботом Cardinal откройте /tdm_lots, выберите запись автовыдачи и формат её TXT.
3. Сверьте имя файла и остаток. Бот проверит первые 10 уникальных аккаунтов и покажет состояния наград и примеры недостающих позиций. Для получения данных аккаунты должны быть известны оркестратору по логину.

Предпросмотр читает инвентарь и настройки автовыдачи. «Получено на Twitch» означает отметку Twitch. Выдачу в игре проверяйте отдельно. Дата снятия в Telegram пока неизвестна.

Для ручной диагностики можно запустить python3 -B plugins/tdm_lot_preview.py configs/tdm-lot-preview.json из корня Cardinal. Пример файла лежит рядом с плагином в репозитории. Параметр use_telegram_selection со значением true использует сохранённый выбор бота оркестратора.
