# Лоты Twitch Drops для FunPay Cardinal

Для первой установки на VPS см. [пошаговую инструкцию с командами](INSTALL_RU.md).

Плагин рассчитан на sidor0912/FunPayCardinal. Загрузите tdm_lot_preview.py через меню плагинов бота Cardinal. Если команда /tdm_lots не появилась после загрузки, перезапустите Cardinal один раз.

## Подключение контейнеров

Передайте обоим сервисам один и тот же ORCHESTRATOR_LOT_PREVIEW_TOKEN длиной от 32 символов. Значение храните в локальных файлах окружения Compose. Если сервисы делят один localhost, дополнительных параметров не нужно.

Для отдельных контейнеров создайте на VPS отдельный каталог /opt/tdm-light-orchestrator/cardinal-ipc с владельцем 10001:10001 и режимом 0750. Добавьте к существующим volumes оркестратора:

```yaml
- /opt/tdm-light-orchestrator/cardinal-ipc:/run/tdm-cardinal
```

Добавьте к volumes Cardinal тот же каталог с доступом только на чтение:

```yaml
- /opt/tdm-light-orchestrator/cardinal-ipc:/run/tdm-cardinal:ro
```

Добавьте в environment обоих сервисов:

```yaml
ORCHESTRATOR_CARDINAL_SOCKET: /run/tdm-cardinal/preview.sock
ORCHESTRATOR_LOT_PREVIEW_TOKEN: ${ORCHESTRATOR_LOT_PREVIEW_TOKEN:?set a local preview token}
```

Сокет доступен владельцу и группе 10001, а также root. Если Cardinal работает от другого непривилегированного пользователя, добавьте сервису дополнительную группу 10001. Пересоздайте оба сервиса через их Compose-проекты. Если после аварийного завершения остался старый сокет, удалите preview.sock при остановленном оркестраторе и запустите сервис снова.

## Подключение лота через Telegram

1. В боте Cardinal откройте `/tdm_lots`, выберите запись автовыдачи и нажмите «Настроить состав». У лота должен быть собственный TXT и шаблон сообщения с `$product`. Выключите встроенную автовыдачу на самом FunPay, чтобы заказ обрабатывал Cardinal.
2. В боте оркестратора откройте «Лоты». Загрузите кампании для нужной игры из Twitch или добавьте кампанию вручную по ID. Для исторических кампаний, которых больше нет в каталоге Twitch, используйте ручной ввод. Этот каталог не добавляет игры в фарм.
3. Откройте «Состав лота» и выберите лот по названию. Выберите игру, затем отметьте все или отдельные награды в нужных кампаниях. Нажмите «Проверить состав», затем «Сохранить состав». Для ручного открытия доступен «Ввести код лота». Код целиком копируется кнопкой в карточке Cardinal.

   При поиске завершившейся кампании редактор проверит сохранённую историю и до пяти аккаунтов из TXT лота. Чтобы обновить выборку, нажмите «Настроить состав» в Cardinal. Для формата `логин:пароль` оркестратору нужны уже известные данные Twitch. Пароли из товарного файла в запрос поиска не передаются.
4. Формат `логин:пароль` подходит, когда оркестратору известны OAuth и Twitch user ID. Если аккаунтов в оркестраторе нет, загрузите полный TXT в «Лоты → Загрузить аккаунты лотов». Полный TXT в Cardinal уже содержит данные для проверки. Имейте в виду, что шаблон автовыдачи отправляет покупателю исходную строку TXT в выбранном формате.
5. Вернитесь в `/tdm_lots` и нажмите кнопку проверки формата. Бот прочитает инвентари первых десяти строк без изменения файла, лота или пула аккаунтов.
6. После проверки откройте «Настроить автоматизацию» и выберите формат файла. Если Cardinal не может сопоставить запись и лот автоматически, используйте команду, которую выводит бот, с числовым ID из ссылки `offer?id=…`. Автоматизация сначала включается только для выбранного лота.

Код вычисляется по названию записи в настройках автовыдачи Cardinal, а автоматизация хранит числовой ID FunPay и имя TXT. Для изменения даты редактируйте название лота на FunPay, сохранив остальную часть названия и запись автовыдачи в Cardinal.

Для управляемого лота плагин сохраняет отключение штатного обработчика в `configs/auto_delivery.cfg`. Выдачу по тому же TXT и шаблону обрабатывает плагин. Не включайте штатную выдачу обратно для этой записи, пока она управляется плагином. Остальные записи Cardinal продолжают обслуживаться штатным обработчиком.

## Что работает в фоне

- Cardinal циклически проверяет остаток. Перед автовыдачей аккаунты снова проверяются по точным ID кампаний и наград. При неполном ответе Twitch выдача конкретного аккаунта блокируется. Отметка «Получено на Twitch» не подтверждает доступность награды для другого игрового аккаунта.
- `[ДО 23.11]` в названии означает 23 ноября в 00:00 МСК. Для однозначной даты можно использовать `[ДО 23.11.2026]`. Лот снимается также при пустом остатке или после полного прохода, который показал отсутствие части обещанных наград у каждого доступного аккаунта. Ошибка Twitch не считается отсутствием наград.
- Карточка «Сроки и состав» показывает предложенную дату, если для каждой кампании администратор сохранил подтверждённый срок и ссылку. Берётся самый ранний срок из набора. Без этих данных надёжная дата неизвестна.
- После подтверждения снятия и проверки оплаченных заказов непроданные аккаунты ждут проверки инвентаря. В свободный пул возвращаются только аккаунты с пустым инвентарём, строки которых Cardinal сам убрал из TXT. Если остаток изменился одновременно со снятием, бот покажет причину задержки.
- Перед отправкой плагин ещё раз проверяет оплату. После перезапуска он сверяет оплаченные заказы, появившиеся после включения защиты, и восстанавливает подтверждённые резервы. При неопределённом результате отправки сверяет чат FunPay и сохраняет резерв, пока там нет подтверждения. До ручной выдачи проверьте чат и состояние заказа.
- Уведомления о снятии и возврате сохраняются в Cardinal и отправляются повторно при временной недоступности Telegram.
- Настройки и журнал резервов хранятся в `storage/tdm-managed-lots.json` Cardinal, поэтому том `storage` должен сохраняться при обновлении контейнера. Пока лот управляется плагином, оставляйте его загруженным и не заменяйте TXT вручную в процессе снятия. Плагин не удаляет саму карточку лота FunPay, он снимает её с продажи.

Старый ручной предпросмотр остаётся в «Лоты → Ручной предпросмотр». Для него также доступна диагностика `python3 -B plugins/tdm_lot_preview.py configs/tdm-lot-preview.json` из корня Cardinal. Пример файла лежит рядом с плагином в репозитории.
