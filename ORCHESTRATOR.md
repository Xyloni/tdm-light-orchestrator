# Оркестратор TDM Light

Оркестратор запускается из того же бинарника и выделяет отдельный процесс майнера каждой активной игре. Внутри игры одновременно фармится одна группа одной кампании. Получение заработанных наград остаётся ручным.

## Проверка на Windows

Запустите `start-orchestrator.bat` двойным щелчком. Для сборки нужен Go 1.22 или новее в PATH. Скрипт соберёт `tdm-light-orchestrator.exe` и запустит оркестратор в открытой консоли. Для остановки нажмите Ctrl+C.

Откройте `http://127.0.0.1:8787`. Состояние и логи сохраняются в `orchestrator-data`. Обычный запуск без флага по-прежнему запускает самостоятельный майнер.

## Linux VPS из GHCR

После публикации новой версии в репозитории используйте тот же установщик, что и для самостоятельного майнера, с флагом `--orchestrator`. На VPS нужны Docker Engine, Compose, curl и sudo.

```sh
curl -fsSL https://raw.githubusercontent.com/Xyloni/tdm-light-orchestrator/main/deploy/install-vps.sh -o /tmp/tdm-light-install.sh
sudo bash /tmp/tdm-light-install.sh --orchestrator
```

Установщик скачивает готовый образ `ghcr.io/xyloni/tdm-light-orchestrator:latest` и запускает оркестратор в `/opt/tdm-light-orchestrator`. Настройте бота через панель, доступную по SSH-туннелю. Для самостоятельного майнера запустите тот же установщик без флага. Его каталог по умолчанию — `/opt/tdm-light-orchestrator-miner`.

```sh
cd /opt/tdm-light-orchestrator
sudo docker compose logs -f orchestrator
sudo bash update.sh
sudo bash update.sh --rollback
```

Состояние оркестратора хранится в `data/orchestrator/state.json` внутри установочного каталога. Обновление и откат заменяют образ контейнера. Для миграции с ПК остановите оба процесса, перенесите файл в этот путь с владельцем `10001:10001` и правами `0600`, затем запустите оркестратор на VPS. Токены самостоятельного майнера и оркестратора должны быть разными, если работают оба режима.

## Linux VPS с Docker из архива или исходников

На VPS можно использовать исходники или архив `tdm-light-vps-ubuntu.tar.gz`, который создаётся скриптом `build-vps.ps1` и содержит готовые бинарники для Linux amd64 и arm64. После распаковки перейдите в `vps-linux`. Подготовьте каталог данных для UID 10001.

```sh
sudo install -d -m 0700 -o 10001 -g 10001 data-orchestrator
docker compose -f docker-compose.orchestrator.yml up -d --build
docker compose -f docker-compose.orchestrator.yml logs -f orchestrator
```

Compose использует сеть хоста Linux. Панель слушает только loopback VPS. Для локальной работы с ПК можно открыть SSH-туннель и затем зайти на `http://127.0.0.1:8787`.

```sh
ssh -L 8787:127.0.0.1:8787 user@vps
```

В веб-панели откройте **Бот управления**, выберите Telegram или Discord, введите токен бота и числовой ID владельца, затем сохраните. Оркестратор обновит подключение без перезапуска майнеров. Для отключения выберите «Отключено». При смене ID владельца оставьте поле токена пустым, чтобы сохранить токен той же платформы.

До первого сохранения в панели оркестратор подхватывает ранее настроенных ботов из `config.env` и переменных окружения. После сохранения действует выбранная в панели платформа. Настройка разрешений Discord описана в основном README. Используйте выделенные токены для оркестратора, если одновременно запущен самостоятельный майнер.

В `state.json` хранятся настройки, очереди, история, пулы, учётные данные Twitch и настройки бота, включая токен. Каталог данных предназначен для одного процесса оркестратора. Храните его и резервные копии приватно.

## Управление

Начните с `/help`. Справка разделена на игры (`help games`), аккаунты (`help accounts`), настройки (`help settings`) и нагрузку (`help load`). В Telegram откройте `/menu` для кнопок или отправьте `/help settings`. В Discord выберите `/help` и укажите `settings` в поле `topic`. Общие команды включают `/pause_game`, `/resume_game`, `/restart_game`, `/exclude_reward` и `/notifications`. Эти же примеры доступны в разделе «Справка» веб-панели. В веб-панели для каждой операции есть отдельная форма. Числовые настройки задаются в полях, а диагностика HTTP, единый лог и Twitch PubSub переключаются тумблерами. Настройки майнера применяются со следующей группы.

| Команда | Действие |
| --- | --- |
| `status` | Игры, кампании, состояние групп, размеры пулов и общая нагрузка |
| `errors Название игры` | Пропуски по активной или последней кампании игры |
| `exclusions Название игры` | Показать исключения наград для игры |
| `exclude Название игры \| Полное название награды` | Исключить награду только для этой игры |
| `include Название игры \| Полное название награды` | Убрать отдельное исключение игры |
| `add 1000 Название игры` | Добавить игру по точному названию категории Twitch и задать целевой размер пула |
| `stop Название игры` | Поставить игру на паузу и остановить майнер. Пауза сохраняется после перезапуска оркестратора |
| `resume Название игры` | Вернуть игру в очередь. При активной кампании продолжится сохранённая группа |
| `restart Название игры` | Перезапустить работающий майнер игры, сохранив очередь и состав группы |
| `remove Название игры` | Показать последствия удаления |
| `/remove_game confirm release Название игры` | Удалить игру вместе с историей и вернуть аккаунты в свободный пул. Вариант `confirm delete` удаляет записи аккаунтов. В Discord выберите действие кнопкой |
| `target 800 Название игры` | Изменить цель добора из свободного пула. Снижение цели не отвязывает уже закреплённые аккаунты |
| `limits 2 1000` | Изменить лимиты активных игр и аккаунтов |
| `mode resources` / `mode speed` | Включить экономию ресурсов или использовать свободную ёмкость. Режим действует со следующей группы |
| `timing 10 75 120` | Добавить к прогнозу 10 минут запаса, использовать стартовую скорость 75% до первых замеров и искать кампании каждые 120 секунд |
| `miner diagnostics on` | Переключить `diagnostics`, `single_log` или `pubsub` через `on` и `off` |
| `assign login Название игры` | Закрепить аккаунт за игрой |
| `free login` | Вернуть аккаунт в свободный пул |
| `trim` | Предпросмотр ручного снижения общей нагрузки |
| `trim confirm` | В течение двух минут подтвердить остановку наиболее отстающих. Если список изменился, оркестратор покажет новый предпросмотр |

В панели введите короткое название и нажмите «Найти в Twitch», затем выберите нужную категорию. Для поиска нужен Twitch-аккаунт хотя бы в одном пуле. При недоступности поиска можно добавить точное название вручную. Для удаления откройте «Удалить игру» в её карточке и подтвердите действие.

В веб-панели выберите игру или свободный пул и загрузите файл формата `account.txt`. Если аккаунт уже закреплён за другой игрой, переместите его отдельной формой. Через Telegram и Discord новые аккаунты загружаются в свободный пул. Повторная загрузка обновляет данные существующего аккаунта с тем же логином и Twitch user ID. При постановке игры на запуск оркестратор добирает свободные аккаунты до её цели и сохраняет закрепление. Если свободных не хватает, игра начинает с доступным пулом.

В разделе «Аккаунты» есть очистка выбранного пула. Очистка свободного пула удаляет записи из оркестратора. При очистке пула игры выберите удаление записей или возврат аккаунтов в свободный пул. Игра остаётся на паузе. Работающий майнер игры сначала нужно остановить.

## Выгрузка аккаунтов в Telegram

В личке владельца откройте `/menu`. В разделе «Аккаунты» можно выгрузить свободный пул, а в карточке игры — её пул. Бот отправит документ в формате `account.txt` после подтверждения. При очистке пула или удалении игры можно выбрать «Выгрузить .txt и удалить». Удаление начинается после подтверждённой отправки, если состав пула и данные аккаунтов за это время не изменились.

Файл содержит OAuth-токены и сохранённые пароли. Оркестратор формирует его в памяти. Предел одной выгрузки — 2 МБ, как при обратной загрузке через бота.

## Статистика

В шапке панели показываются аккаунто-минуты, готовые награды и завершённые кампании. Через `/stats` доступен итог за сегодня, семь календарных дней и всё время. Для фильтра по игре укажите её полное название в Telegram или в поле `game` команды Discord. В меню Telegram также есть кнопка «Статистика».

Минуты и готовые награды накапливаются с первого запуска этой версии. Первая подтверждённая отметка Twitch для аккаунта и награды служит исходной точкой. Уже готовые при первой проверке награды в новый счётчик не попадают. Сохранившиеся итоги прежних кампаний учитываются в общем числе кампаний без привязки к дате. Счётчики хранятся в состоянии оркестратора отдельно от журналов.

## Правила игр, карантин и история

В карточке игры можно переопределить режим и запас времени. Значение 0 использует общий запас, а общий режим наследуется отдельно. Изменения применяются при расчёте следующих групп.

Ошибки авторизации подтверждаются повторными проверками, после чего аккаунт остаётся в пуле игры и исключается из новых запусков. Загрузка нового OAuth-токена с тем же Twitch ID снимает карантин. Список есть в панели, в Telegram в разделе «Аккаунты» и через `/quarantine`.

История кампаний хранится в состоянии независимо от ротации логов. Замеры прогноза и факта появятся у групп, завершённых после обновления. В ботах отчёт доступен через `/campaign_report`, правила игры через `/game_policy`.

## Предпросмотр и симулятор

В разделе настроек панели доступен предпросмотр по выбранной игре или всем играм. В ботах используйте `/preview_schedule`, например `all | resources`, либо кнопки Telegram в настройках и карточках игр. Для предпросмотра всех игр сохраняются индивидуальные переопределения режимов. Для одной игры можно сравнить оба режима. Оценка учитывает только известные кампании и текущие данные.

Симулятор в панели и команда `/simulate_schedule` рассчитывают группы на вымышленных данных. Например, `1 20 | 30 30 90 | 20 45 120` задаёт один слот, лимит 20 аккаунтов и две кампании с разной длительностью группы и дедлайном. Симулятор не обращается к Twitch и не меняет состояние.

## Уведомления

Суточная сводка включается в настройках уведомлений панели, в Telegram через «Уведомления» или командой `/daily_digest`. Укажите время сервера в формате `HH:MM`, например `21:00`. Значение `off` отключает рассылку. Сводка охватывает предыдущий календарный день и отправляется не чаще раза в сутки.

В веб-панели и в Telegram через «Уведомления» можно отключить всю доставку или выбрать отдельные события. Общий переключатель сохраняет выбранные типы. Через команду `/notifications` можно посмотреть настройки, а параметр `all off` приостанавливает доставку. Новые подробные события, включая запуск групп и готовность отдельных наград, включаются по желанию.

## Telegram и наблюдение

В личке бота отправьте `/start` или `/menu`. Кнопки в сообщении открывают статус, игры, настройки режима и справку. В карточке игры можно остановить майнер, возобновить работу, перезапустить или подтвердить перегруппировку. Меню у поля ввода содержит быстрые команды.

Панель и `/status` показывают последний успешный опрос Twitch. Боты сообщают после трёх неудачных опросов подряд и после восстановления каталога. Для ожидающих групп прогноз скорости использует нижний квартиль свежих замеров и постепенно обновляется при замедлении или восстановлении начисления.

Журнал решений сохраняется в `logs/orchestrator-ГГГГ-ММ-ДД.log`. В записи запуска группы указаны дедлайн, оценка скорости, запас, число ожидающих аккаунтов и расчётный размер группы. Логи майнеров также разбиты по датам. Оркестратор хранит логи за сегодня и предыдущие два календарных дня по времени машины. Старые файлы прежнего формата удаляются после 72 часов с момента последней записи.

В личке владельца Telegram откройте **Меню → Скачать логи** и выберите день. В Discord используйте `/download_logs` с необязательным полем `date` в формате `ГГГГ-ММ-ДД`. Пустое поле означает сегодня. ZIP содержит журнал решений и дневные файлы майнеров. Лимит выгрузки составляет 8 МиБ для ZIP и 64 МиБ для исходных файлов.

## Планирование

- Каталог опрашивается через Twitch с любым рабочим аккаунтом. В очереди участвуют кампании только для настроенных игр. Если сроки отсутствуют, оркестратор повторяет поиск и показывает причину в статусе.
- Игра сохраняет слот, пока у неё есть готовая следующая кампания. Если в каталоге видна будущая кампания этой игры, при паузе слот освобождается, а игра получает приоритет на следующий свободный слот при возобновлении. Кампании, которых Twitch ещё не показал, планируются по мере обнаружения.
- Размер следующей группы рассчитывается по дедлайну, суммарным требованиям к минутам, запасу, измеренной скорости и общей нагрузке. Уже начавшуюся группу можно сократить подтверждённой командой `trim`.
- Если требуемая группа превышает лимит, она запускается с предупреждением. Подтверждённое сокращение исключает остановленные аккаунты из текущей кампании, сохраняя их в пуле игры.
- После серии ошибок авторизации аккаунт отмечается как пропущенный. Группа продолжает ждать завершения остальных аккаунтов, затем переходит к следующей группе.
